# tfd-ihc: Organizador Acadêmico Inteligente (IHC, UFG)
- Escopo: escopo.pdf (app web de organização acadêmica). Ignorar nome e matrícula.
- Stack: HTML/CSS/JS puro, sem build. Dados em data/db.json via server.js (node server.js, porta 3000); sem servidor, localStorage (chave oai.v2) como reserva.
- Arquivos: index.html, css/style.css, js/app.js. Abrir index.html no navegador.
- Relatório de apoio à apresentação: relatorio.pdf (fonte docs/relatorio.html). Regerar com Edge headless --print-to-pdf.
- Regra: a cada interação, atualizar registro.md (prompt e output transcritos) até a conclusão.
- Estado do trabalho: ver ESTADO.md.
